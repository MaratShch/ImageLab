## Version caveat (recorded in the provenance)

The paper's 5247 is rated **EI 125** — the improved "5247/II" (1979+).
The profile `EASTMAN_5247_1974` targets the 1974–1982 era at EI 100.
Speed difference is a product-version difference, recorded, not adopted.
When Fig 7/11a shapes are digitised they adopt with a version note.
