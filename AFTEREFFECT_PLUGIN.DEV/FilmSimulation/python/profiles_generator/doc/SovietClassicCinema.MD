# Soviet Classic Cinema — film stock research notes

Compiled 2026-08-11 from an owner question. Scope: fourteen classic Soviet
titles; what film stock each was shot on, with the attribution errors in the
original list corrected. **"-" means: no trusted source found — not
"unknown to history", just absent from the sources checked.**

Evidence classes follow the database convention (`NotFound.md` §9b):
[C1] documented, [C2] documented equivalence, [C3] inference from
era/studio practice, [C4] guess. Nothing below is [C4]: where only a guess
would be possible, the cell carries "-".

Soviet reality this table lives in: per-title stock records were almost
never published. The USSR had no end-credit / American-Cinematographer
culture of naming the negative. Real answers sit in production files
(РГАКФД, Госфильмофонд) and period journals («Искусство кино», «Техника
кино и телевидения»).

## Corrections applied to the original list

* №3: «Великая Отечественная» — Роман Кармен; Озеров made «Освобождение».
* №9: «Садко» — Птушко, не Роу.
* №11/12: Гайдай — Леонид, не А.
* №13: title does not exist as given; probable intended film is
  «Ярославна, королева Франции» (1978).
