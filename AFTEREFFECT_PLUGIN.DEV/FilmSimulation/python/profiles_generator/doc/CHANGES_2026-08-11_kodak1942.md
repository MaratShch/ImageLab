# Changes 2026-08-11 (third pass) — Eastman 1942 MP book processed

Owner supplied `PDF/PROFILES/KODAK/Kodak - [1942] - Eastman Motion Picture
Films for Professional Use.pdf`: 98 pages, pure scan with **no text layer**,
processed accordingly — every page rendered and OCR-indexed (tesseract,
psm 4); index of the whole book now exists for search. Copyright 1942,
Eastman Kodak Company, distributed by J. E. Brulatour, Inc.

This is the **first Kodak motion-picture technical publication in the
archive** — NotFound.md §2's core complaint since 2026-07-31. It carries
full specification sheets, each with an H&D curve and a time-gamma /
time-fog family, for the 1942 35 mm nitrate line.

## Profile changes

**`EASTMAN_SUPER_XX_1938` — first manufacturer document, [C1], tier 3 → 2.**
The Type 1232 sheet (PDF p49) is the same product under its period 35 mm
nitrate designation:

* Kodak Film Speed: Sunlight 400 / Tungsten 250 (Weston 100/64, G.E.
  160/100), for SD-21 development to gamma 0.65.
* Recommended IIb control gamma 0.60–0.70 — **brackets the fitted curve
  gamma 0.610**, so the existing curve stands corroborated.
* Resolving power 55 lines/mm in SD-21 → `_RESOLVING_POWER` **as printed**,
  with a fourth unit-convention caveat (development stated, test-object
  contrast NOT stated; not comparable to 1.6:1 / 1000:1 / 30:1 figures).
* Gray nitrate base with anti-halation gray dye — the book states ALL
  Eastman picture negatives carry it, so the profile's moderate halation
  gains are the *residual* the gray base did not stop; comment added
  warning against raising them to "period film" levels without measurement.
* `exposure_index` stays 100 (established period daylight rating): the
  1942 Kodak speed scale predates ASA PH2.5-1960 and admits no constant
  conversion; the raw 400/250 figures live in the provenance verbatim.
* No numeric field changed except the `_RESOLVING_POWER` addition. Grain
  stays [T2-interpolated]: the book grades graininess qualitatively only
  ("medium graininess").

**`EASTMAN_PLUS_X_5231` — context only, [C3].** The Type 1231 sheet
(PDF p48) documents the gray-nitrate **predecessor** of 5231 (the
post-1949 safety-base successor, emulsion revised over the years).
Recorded in provenance as family-adjacent evidence with its figures
verbatim (Sun 240 / Tung 160, SD-21 γ 0.65, R 55 l/mm); **no field
fitted from it** and nothing added to `_RESOLVING_POWER` for 5231 —
that dict is product-specific by contract.
