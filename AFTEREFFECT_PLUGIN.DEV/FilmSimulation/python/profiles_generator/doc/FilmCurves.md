# FilmCurves.md — spectral sensitivity curve usage per stock

Generated by `gen_film_curves_md.py` from `film_profiles.py` (schema v24). 87 of 175 stocks carry digitised per-emulsion spectral curves; every curve is that film's own — never shared across a vendor. As of 2026-08-13 these curves ARE consumed: they drive colour-temperature balance in both the Python reference and the C++ engine (AlgoSpectralSensitivity, spectral_balance_gains). The monochrome-weight and taking-matrix derivations built on the same curves remain OFF by default -- projecting a sensitisation onto three visible primaries derives nonsense for extended-red and infrared stocks; see CHANGES_2026-08-13_spectral_path.md.

Values are relative log10 sensitivity, peak-normalised to 0.0, sentinel −4.0 = below the source plot's floor. Colour stocks carry three sensitive-layer curves, B&W/reseau stocks one panchromatic curve. Full citations (author, document, ORIGINAL release date) live in each profile's `spectral.source` field and in the generated C++ comments. Queue and method rules: `DIGITIZATION_QUEUE.md`.
