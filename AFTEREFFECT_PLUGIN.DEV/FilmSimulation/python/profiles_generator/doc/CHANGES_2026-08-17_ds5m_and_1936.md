## 2. A live bug found while entering it — measured per-channel grain was being discarded

`_grain_v2()` derived per-channel RMS for every colour negative as b ≈ 1.3× and r ≈ 1.1× of
the pooled figure — **unconditionally**, overwriting any value a profile literal had set.
The module already forbids exactly this for the σ(D) shape a few lines below, with a comment
noting "this exact bug ate two rounds of measured FN-64 shape adoptions"; the same guard was
missing for RMS.

It was not hypothetical. **`GEVACOLOR_NEG_682` carries 23 / 16 / 34 read off Fig. 12 of the
Vervoort & Stappaerts SMPTE paper**, and its own comment explains that the ordering
blue ≫ red > green is *the opposite* of the heuristic, because the DIR couplers act on green
and red only. That stock had been rendering as 17.6 / 16.0 / 20.8 — with the documented
inversion erased.

Fixed: the heuristic now applies only when the literal leaves all three per-channel values
at zero. `GEVACOLOR_NEG_682` renders with its measured values for the first time; this is a
**deliberate, visible change to that stock's output**. `TECHNICOLOR_THREE_STRIP` was already
excluded from the colour-negative branch and is unaffected.

## 3. «Методы спектральной сенситометрии», Ю. Н. Гороховский, УФН XVI(4), 1936

`PDF/PROFILES/SOVIET/МЕТОДЫ СПЕКТРАЛЬНОЙ СЕНСИТОМЕТРИИ - 1936.pdf` — 17 pages, full text
layer, all pages reviewed.

**Nothing was entered from it, and that is the correct outcome.** It is a *methods review* —
how spectral sensitivity is measured, not what any particular emulsion measures. Note the
author: this is the same Gorokhovskii whose 1970 sensitometric handbook is on our wanted
list, publishing here in 1936.

**What it does carry, recorded because it changes how period data must be read:**

- **Criterion conventions differ between period sources.** Bilz (1935) measured to
  **D = 0.1 above fog**; the ГОИ Leningrad work of 1934–35 measured to **D = 1.0 above fog**.
  Both report erg/cm². Mixing them silently corrupts any comparison.
- **Bilz's own error estimate is 19 %** at D = 0.1 — a direct statement of how much any
  1930s spectral figure can be trusted.
- **The methodological spread is enormous.** For the same class of material the green
  (546 nm) to blue (436 nm) sensitivity ratio came out at **4–13 % in the ГОИ work,
  30–60 % for Bilz and 20–45 % for Stobbe** — differences driven by prism versus diffraction
  spectrographs, not by the emulsions. Any single period spectral number is therefore
  method-bound, and this is now the reason to distrust one.
- Table 3 (p 514) gives numeric sensitivities at 436 / 546 nm for named Agfa ortho and
  panchromatic films, old versus new measurement methods.
- Fig. 6 plots measured curves for Agfa Isochrom-Portraitfilm, Isopan-Portraitfilm and
  Isopan-ISS-Planfilm. Fig. 7 plots Persenso (Perutz), Monarch / Hypersensitive / Soft
  gradation (Ilford) and **«Изопанхром ФОКХТ»** — the only measured spectral curve for any
  1930s **Soviet** material anywhere in the corpus.

**Why «Изопанхром» was not attached to `SOVIET_PANCHROM_1939`.** It is tempting: that stock
has no documentation of any kind and the engine falls back to generic weights. But
Изопанхром ФОКХТ measured at ГОИ in 1934–35 is a *different, named product* from a stock we
model as a generic 1939 Soviet panchromatic emulsion, and grafting one onto the other is the
same error the project already refuses for FP4 vs FP4 Plus and F125 8530 vs 8532. The figure
is also five crossing dashed curves in a raster — the case that needs the dash-aware tracer.
Recorded as a candidate in `DIGITIZATION_QUEUE.md` with the identity caveat attached, so the
decision is available rather than silently made.
